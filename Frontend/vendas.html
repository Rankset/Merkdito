Integração com o aplicativo de vendas

O app deve enviar a venda somente depois que ela for confirmada no caixa. A API grava a venda, reduz o estoque e registra a saída na mesma transação. Se o app reenviar a mesma venda, use sempre o mesmo IdVendaExterna; a API reconhece a repetição e não reduz o estoque duas vezes.

Endpoint: POST /api/Vendas/sincronizar com JWT de cliente no cabeçalho Authorization: Bearer .... O contrato JSON está documentado em Docs/INTEGRACAO_APP_VENDAS.md.
