Como funciona

Use um CSV para atualizar os dados cadastrais de produtos já existentes. Identifique cada produto pelo ID ou código de barras. O sistema compara os dados atuais com os valores propostos e exibe uma prévia antes de salvar.

Importante: células vazias não alteram o campo correspondente. Esta tela não altera a quantidade em estoque nem a categoria; use “Atualizar Estoque” para o saldo e a tela do produto para alterar a categoria. Nenhum produto será criado por esta operação.

1. Selecione a planilha

2. Confira antes de aplicar

Linhas sem produto correspondente, identificadores conflitantes, identificadores repetidos ou valores inválidos são recusados. A API valida todas as alterações e salva em uma transação; se o lote for rejeitado, nenhuma alteração é aplicada. Em caso de timeout, consulte o catálogo antes de repetir.
