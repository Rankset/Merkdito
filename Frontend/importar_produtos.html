Importar produtos

Cadastre vários produtos de uma vez a partir de um arquivo CSV.

Voltar aos produtos

1. Prepare o arquivo

Use um arquivo CSV com separador ponto e vírgula (;) e codificação UTF-8. O modelo contém os cabeçalhos necessários. A coluna categoria deve corresponder ao nome de uma categoria ativa no seu estabelecimento.

Conferir categorias
  • Colunas: nome, codigoBarras, descricao, preco, quantidadeEstoque, estoqueMinimo, categoria e ativo.
  • Preço pode usar vírgula decimal (por exemplo, 12,90). Quantidade e estoque mínimo devem ser números inteiros.
  • O código de barras é opcional. Quando informado, deve ser único dentro do catálogo da empresa.
  • A importação cria produtos novos; não atualiza nem substitui produtos já cadastrados.

Os produtos válidos são enviados em uma única requisição. A API valida todos os itens e confirma o lote em uma transação; se o lote for rejeitado, nenhum produto é cadastrado. Em caso de timeout ou perda de conexão, consulte o catálogo antes de tentar novamente.

3. Confira a prévia

Corrija no arquivo de origem as linhas marcadas com erro e selecione o CSV novamente. Apenas linhas sem erros serão enviadas.
